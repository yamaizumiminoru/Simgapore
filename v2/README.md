# Simgapore 2.0 — 国を経営する

**1965年から2025年まで、予算と人材を配分し、地区の強みを育てる国家経営ゲーム。**

首相リー・クアンユーの立場から始め、世代交代を経て国を率います。勝利条件は、2025年の年間名目GDPを米ドルに換算し、史実のシンガポールを超えることです。

## 遊び方

ルートの `Simgapore2.html` を保存し、ChromeまたはEdgeで開いてください。オフラインで遊べます。

水と住宅の充足率を確認し、国家政策と地区の投資優先度を決めます。「次年度を試算」で見通しを確かめ、「年を運営する」で決算を進めてください。設定は翌年へ引き継がれます。

「史実からのヒント」では、年代に応じた投資方針を紹介しています。「参考配分を政策に入れる」で国家政策と地区の優先度へ反映し、そこから自分の方針に合わせて調整できます。

## 経営するもの

- **地区と産業**：ジュロン、南部港湾、都心、チャンギ、北部住宅、中央集水域、西部研究、東海岸の8地区。開発予算を優先度に応じて配分し、工業・物流・金融・研究・住宅・水の基盤を育てます。
- **生活と資源**：水と住宅の不足は現在の生産を押し下げ、決算時に支持へ影響します。エネルギーの輸入コストは世界価格・為替・省エネ効率・調達先分散によって変わります。技術が育つと高度再生水、さらに海水淡水化へ投資できます。
- **資本と人口**：外国資本、外国人の働き手、専門人材をそれぞれ受け入れます。国内で生まれる付加価値がGDPに加わります。子育て・生活支援は出生と支持を支え、子供は18歳から働き手の世代に入ります。
- **財政と為替**：税収と予算、手元資金、外貨準備、開発債を管理します。国債は10年固定利率で、新規発行や借換え時の金利は純負債・利払い能力・世界金利・信用に応じて決まります。GDPの米ドル換算には年平均の為替レートを使います。
- **政権の運営**：選挙年に得票率と議席率が表示されます。権限集中は投資の実行を速める一方、誤判断時の損失と修正の遅れを大きくします。国民と党内の信任、資金調達能力を保つことが長期の成長戦略を支えます。

画面上部には、**その年の史実GDP比**と**2025年の目標比**を常時表示します。60回の年次決算を経た2025年に最終判定し、途中の失脚や資金調達危機はゲームオーバーとなります。年ごとのGDP・人口・支持は「成長の記録」で振り返れます。

## 620倍の成長への道筋

比較には、世界銀行の1965〜2025年の名目米ドル建てGDP系列を用います。FRED掲載の2026年6月30日更新版に固定しています。

| 年 | GDP（米ドル） |
|---|---:|
| 1965 | 974,644,096.144674 |
| 2025 | 603,869,516,998.738 |

倍率は **619.5795156倍**。ドル建てGDPは、人口・設備・技能による生産の拡大、国内物価、為替の変化によって動きます。ゲームでは、それぞれを計算して年間の成績を出します。史実系列は比較と勝敗判定の基準です。

参考方針は、輸出工業化・外国投資・港湾基盤を足場に、教育と専門人材による技術の吸収を進め、金融・研究・サービスへ配分を広げるものです。成長に合わせて住宅・水・エネルギーの基盤を整えます。

## 資料とゲームの設定

GDPの比較系列、選挙年、出来事の年、技術史の説明は下記の資料に基づきます。人口の初期内訳、地区の境界、投資効率、成長式、支持・議席の計算はゲーム用の設定です。参考配分の数値も、史実の成長戦略を参考にした攻略設定です。

為替は対米ドルにまとめ、1967年以前も同じ通貨単位で計算します。現実のシンガポールの為替政策は複数通貨をまとめた指標を用います。ゲームの開発債は予算調達に使えますが、現実の公的債務には資産の裏付けや使途の制約があります。NEWaterは史実では2003年に本格導入され、ゲームでは1998年以降かつ人材・技術水準58以上で導入できます。

## 保存と互換性

進行状況はブラウザに自動保存されます。HTMLの場所やブラウザを変える前には「セーブを書き出す」でJSONファイルを保存し、移動先の「セーブを読む」で続きを再開してください。

2.0の保存キーは `simgapore-v2-save`、JSON形式は `Simgapore2` / version 2です。旧v0.6は `Simgapore.html` と専用の保存キーで別々に管理しています。旧版のセーブは旧版で開いてください。形式に問題があるファイルの読み込みは中止し、現在の状態を保ちます。

## ビルドと検証

```sh
python v2/build.py Simgapore2.html
python v2/verify.py Simgapore2.html
BALANCE=1 TEST_REPORT=v2/reports/engine.json node v2/tests/engine.cjs Simgapore2.html
pip install playwright==1.57.0
python -m playwright install --with-deps chrome msedge
python v2/tests/browser.py Simgapore2.html --channels chrome,msedge --out v2/reports
```

配布物はソースから生成する単一HTMLです。検証では、ソースと配布物のハッシュ、旧v0.6の保存、経営計算、起動、操作、保存・読み込み、1965〜2025年の通しプレイを確認します。Chrome・Edgeのブラウザ検査はLinux上のCIで実行し、成功した配布物とレポートを公開します。

実行結果は [Actions](https://github.com/yamaizumiminoru/Simgapore/actions/workflows/simgapore2.yml) と [`v2/reports/`](reports/) に記録されます。

### 参考方針の試走

バランス調整に使っていない乱数2001〜2200で、それぞれの方針を200回試走した結果です。

| 操作方針 | 勝利 / 200回 | 終了時GDP中央値（十億米ドル） |
|---|---:|---:|
| 毎年、参考配分を適用 | 200 | 711.21 |
| 初期設定を維持 | 0 | 140.78 |
| 参考配分・外国資本は抑制 | 0 | 297.69 |
| 参考配分・教育予算0％ | 0 | 214.34 |
| 参考配分・外国人材は抑制 | 0 | 274.86 |
| 参考配分・水予算0％ | 0（全回途中失脚） | 8.85 |

「抑制」はゲーム内の低い受入水準です。この試走で、参考方針による目標への到達と、投資配分による結果の変化を確認しています。
