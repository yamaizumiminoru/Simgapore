# Simgapore 2.0 — 国を経営する

**1965年から2025年まで。勝利の指標は、年間の名目米ドル建てGDPだけ。**

作者の希望により再開した、マクロ経営版の試作です。個々の建物や政府系企業を操作するゲームではありません。地区への投資配分、国家予算、外国資本・人材、為替、借入を組み合わせます。

旧版はルートの `Simgapore.html` にそのまま保存。新しい配布物は `Simgapore2.html` です。セーブ枠も完全に分離しています。旧READMEと後継開発者募集は変更していません。ライセンスは未選択のままです。

## 遊ぶ

ルートの `Simgapore2.html` を保存し、ChromeまたはEdgeで開きます。サーバー、アカウント、APIキー、外部素材の取得は不要です。生成前のソースからは、以下で配布物を作れます。

```sh
python v2/build.py Simgapore2.html
```

最初は水・住宅の充足率を確認し、政策と地区の優先度を決め、「次年度を試算」してから年を進めます。設定は翌年に持ち越されます。迷ったら「史実からのヒント」にある参考配分を使ってください。これは通常の政策を設定するだけで、資金や成長への隠れた加算はありません。難易度の選択はありません。

## 何が変わったか

- 1965〜2025年の60回の年次決算。最終勝利は2025年GDPが史実を超えること。途中の失脚はゲームオーバー。
- **同じ年の史実比**と**2025年の目標比**を常時表示。
- ジュロン、南部港湾、都心、チャンギ、北部住宅、中央集水域、西部研究、東海岸の8地区。自動配分で個別建設をなくしました。地図は模式図です。
- 水・住宅が不足すると、現在の生産量に即座にマイナス。支持は決算で反応します。
- エネルギーは主に輸入価格と供給先の集中という制約。効率化・調達先分散・為替がコストを左右します。
- 外国資本、外国人の働き手、外国人専門人材を別々に設定。国内で生まれる付加価値は所有者の国籍にかかわらずGDPです。海外への利益送金をGDPから引く誤った処理はしません。
- 出生率・出生数・年齢別人口。出生は将来の労働力であり、翌年から働き手にはなりません。
- 技術を蓄積するとNEWater（高度再生水）、さらに海水淡水化へ進めます。
- 対米ドルの為替のみ。年間GDPの換算は年平均相場。通貨高には輸出への負担と外貨準備のコストがあります。
- 開発債は10年固定金利。新規発行・借換え時に、純負債・利払い能力・世界金利・信用が効きます。既存債のクーポンは勝手に変わりません。
- 選挙年の得票・議席表示、党内信任、権限集中の実行力と下振れリスク。
- 丁寧な導入、遊び方、モデルの限界、出典を内蔵。圧縮ローダーを使わない通常の単一HTML。

## 620倍は何を意味するか

比較は全61年を**同じ世界銀行の名目米ドル建てGDP系列**で固定しています。FRED掲載の2026年6月30日更新版です。

| 年 | GDP（米ドル） |
|---|---:|
| 1965 | 974,644,096.144674 |
| 2025 | 603,869,516,998.738 |

倍率は **619.5795156倍**。実物の生産量や給料が620倍という意味ではありません。人口・資本・技能の実質成長に、国内物価と為替の変化が重なります。ゲームでもこの3つを分けています。

成長式はプレイヤーの投資・人材・技術・資源制約から算出します。史実のGDPに追いつくよう強制補正する処理はありません。史実系列は比較と勝敗判定に使います。

## 史実から攻略へ

輸出工業化・外国投資・港湾基盤を足場に、国内教育と専門人材による技術吸収を進め、研究・金融・サービスへ配分を広げる方針を、通常のプレイヤー操作へ落とし込みました。住宅・水・エネルギーの備えも成長に必要です。

ただし、これは歴史から着想を得たゲーム用モデルです。初期人口の内訳、投資効率、政権支持、地区境界、事件の影響量などは架空の簡略化です。回帰分析で推計した経済モデルでも、権威主義の効果を実証するモデルでもありません。参考配分は史実の政策数値の再現ではありません。

**特に現実との違い：** シンガポールは複数通貨をまとめた指標を管理しており、対米ドル一本ではありません。実際の公的債務には対応する資産があり、多くの国債収入は一般歳出へ自由に使えません。このゲームの自由な開発債発行や危機の閾値を、現実の財政診断に使わないでください。NEWaterの史実導入は2003年。ゲームでは1998年以降かつ技能58以上で先行導入を狙えます。

## 保存と互換性

2.0のキーは `simgapore-v2-save`、JSON形式は `Simgapore2` / version 2。旧版の `simgapore-v01` と `simgapore-view-v1` は読み書きしません。旧版や不正なJSONは拒否し、現在の状態を維持します。ファイルやブラウザを移動する前はJSONで保存してください。

## 検証

```sh
python v2/build.py Simgapore2.html
python v2/verify.py Simgapore2.html
BALANCE=1 TEST_REPORT=v2/reports/engine.json node v2/tests/engine.cjs Simgapore2.html
pip install playwright==1.57.0
python -m playwright install --with-deps chrome msedge
python v2/tests/browser.py Simgapore2.html --channels chrome,msedge --out v2/reports
```

ローカルでの結果：経営ロジック32/32、Chromium 144の画面操作31/31。実際のJSONダウンロード・再読込の完全一致、60年間のボタン操作、狭い画面の表示を確認。JavaScriptエラー0。

**ローカルの制限：** 管理ポリシーがfile/HTTPナビゲーションをブロックしたため、Chromiumではset_contentによる画面描画を使用しました。ストレージを偽装せず、ファイル起動と実際のlocalStorage再読込は未検証と明記しています。ブランド版Chrome/Edgeの厳密な検査は同梱CIが担当し、成功時のみ配布HTMLとレポートをルートへ保存します。CIの結果はActionsと `v2/reports/` を参照してください。
