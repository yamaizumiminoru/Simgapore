# Simgapore

**A small island. A big question.**  
Prototype v0.6 — a browser-based city-state management game inspired by Singapore around the time of independence in 1965.

> **Project status:** The original development stops here at the MVP stage.  
> **Looking for someone who would like to carry the idea forward.**

The current prototype is a single-file browser game with a Japanese interface. Download `Simgapore.html` and open it in a modern browser such as Chrome or Edge.

Current features include a historical prologue, play from 1965 to 1990, housing / jobs / water / public finance / public support, construction and policy choices, events, local save data, JSON save export/import, and four-direction map rotation.

The simulation model is intentionally simplified and fictionalized for playability. Historical sections are intended as an introduction, not as a substitute for historical scholarship.

## 🇬🇧 English — Looking for someone to continue the project

Simgapore is a prototype **city-state management game starting around Singapore's independence era in 1965**. The player takes the role of Prime Minister Lee Kuan Yew and makes high-level choices about housing, employment, water, public finance, diplomacy, education, and development.

After finishing the MVP, the original author played *Tropico 4* for research and discovered something useful: micromanagement-heavy simulation games are simply not his cup of tea 😂

Rather than forcing the project in a direction the original author does not personally enjoy, the prototype is being released publicly in the hope that **someone else may want to take the idea further**.

Possible directions include:

- improving the current MVP;
- redesigning it around macro-level national policy rather than building-by-building micromanagement;
- adding deeper historical events and economic systems;
- creating a modern-day sequel, “Simgapore 2”;
- developing it as an educational tool for Singapore history or language learning;
- rebuilding the UI, graphics, or simulation from scratch.

If the idea interests you, feel free to **open an Issue, submit a Pull Request, or fork the repository and experiment**. People interested in becoming the main maintainer are especially welcome.

## Running the prototype

1. Download `Simgapore.html`.
2. Open it in a recent desktop browser.
3. No server, account, API key, or external dependency is required.

## Current version

**Prototype 0.6**

- Japanese-language UI
- historical prologue
- 1965–1990 scenario
- annual action system
- housing, jobs, water, finance and public-support indicators
- construction, policy and event systems
- local autosave and JSON save import/export
- four-direction isometric map rotation
